# 🎲 پلاتو | Plato

باشگاه بازی‌های رومیزی سه‌بعدی — بازسازی از صفر، موج به موج.
A 3D board-game club — rebuilt from scratch, wave by wave.

**Stack:** Vite + React 18 + TypeScript (strict) · React Three Fiber (three.js) · Zustand · Vitest

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit (strict)
npm test           # engine unit tests (vitest)
npm run build      # typecheck + production build
```

---

## پیکربندی میزها

بیشتر بازی‌ها ۲–۴ نفره‌اند؛ **گرگینه ۵–۸ نفره** و **جاسوس ۳–۶ نفره** — صفحهٔ تنظیم میز به‌طور خودکار تا سقف هر بازی صندلی اضافه می‌کند (تا ۸ نفر با نام‌های فارسی: آرش، رستم، سهراب، شیرین، کاوه، تهمینه، فرهاد، گودرز).

## معماری سه‌لایه (هر بازی)

| لایه | مسیر | توضیح |
|---|---|---|
| 🧠 `engine` | `src/games/<id>/engine.ts` | منطق خالص و immutable: `createInitialState / validate / applyAction / legalActions / chooseBotMove` + رابط `GameEngine<S, A>` در `src/core/types.ts`. تصادف فقط از طریق RNG seed شده تزریق می‌شود → کاملاً قابل تست. |
| 🎨 `board` | `src/games/<id>/Board.tsx` | صفحهٔ سه‌بعدی با React Three Fiber: نور/سایه، انیمیشن damp/hop، هایلایت حرکات مجاز، تعامل با کلیک/هاور. |
| 🛍 `shop` | `src/games/<id>/meta.tsx` | اسکین‌های مهره/صفحه/میز + پیش‌نمایش سه‌بعدی + آموزش `fa/en` + لوگوی سه‌بعدی. |

اجزای مشترک:
- `src/core/` — تایپ‌ها، ریجیستری بازی‌ها، `useGameRuntime` (درایور نوبت/ربات/پاداش)
- `src/games/_physics/` — فیزیک دایره‌ای قطعی (بیلیارد، کاروم، بولینگ) — موتور شبیه‌سازی می‌کند و برد سه‌بعدی دقیقاً همان مسیر را بازپخش می‌کند
- `src/ui/` — هاب، ستاپ بازیکن (۲–۴ نفره، انسان/ربات با ۳ سطح)، فروشگاه، HUD، ماژول‌های سه‌بعدی مشترک
- `src/state/` — پروفایل (سکه، خرید، اسکین فعال) با persist روی localStorage
- `src/i18n/` — فارسی (RTL) / English

اقتصاد: برد مقابل ربات → سکه (۴۰/۷۰/۱۲۰ بر اساس سختی) → خرید اسکین از فروشگاه.

## پوشش تست (۲۳۹ تست سبز)

- **دومینو:** پخش ۲۸ تایل، گشاینده با بلندترین دوبله، جهت‌گیری چین، کشیدن/ردشدن، مسدودشدن، امتیاز pips
- **منچ:** خروج با ۶، زدن روی خانهٔ ساده، امن بودن ستاره‌ها، ورود دقیق به خانه، سه‌شش، برد ۴ مهره
- **اُچو:** دک ۱۰۸تایی، تطبیق رنگ/عدد/وایلد، skip/reverse (۲ نفره = skip)، draw2/+4، قرعه‌کشی و پاس، امتیازدهی، reshuffle
- **Connect4:** گرانش، ستون پر، برد افقی/عمودی/مورب، مساوی، بوت بلاک/برد فوری، minimax عمق ۶
- **داما:** حرکت جلو، زدن اجباری، زنجیرهٔ ضربه، تاج‌گرفتن، پادشاه چهارجهته، باخت با بی‌حرکتی
- **شطرنج:** ۲۰ حرکت آغازین، مات احمق، آنپاسان، قلعه (از مسیر مهاجم ممنوع)، ارتقا، پات، کیش‌ومات، مساوی کمبود مهره
- **بیلیارد:** رک ۱۶ توپ، شوت مستقیم، خطای scratch/no-contact، ۸ زودهنگام = باخت، ۸ قانونی = برد، نوبت اضافه فقط با گروه خودی
- **کاروم:** ۱۹ سکه، خط ساده، ملکه + پوشش، برگشت ملکه، خطای ضربه‌زن، برد با آخرین سکه
- **نقطه‌ومربع:** نوبت اضافه با مربع، مربع دوتایی، رد خط تکراری، پایان کامل، برنده(ها)
- **ماروپله:** ورود از ۰، مار/پله، شش = نوبت اضافه، برد در ۱۰۰، boustrophedon
- **بینگو:** کارت‌های یکتا در محدودهٔ ستون، علامت خودکار، خطوط (ردیف/ستون/قطرب + خانهٔ آزاد)، پایان با خط
- **دایس پارتی:** امتیاز هر ۱۳ دسته، پاداش ۶۳+، سه پرتاب + نگه‌داشتن، اجبار امتیازدهی، دور ۱۳ کامل
- **تخته نرد:** موقعیت آغازین ۱۶۷ پیپ، حرکت جهت‌دار، بلاک/زدن بلات، ورود از بار، خانگی دقیق/فراتر، جفت ۴ حرکت، پاس خودکار، برد ۱۵ مهره
- **منقله:** کاشت خلاف عقربه، نوبت اضافهٔ انبار، برداشت گودی خالی، جاروب نهایی، جمع ۴۸ دانه
- **بولینگ:** امتیاز ۳۰۰ کامل، اسپر/استرایک بازگشتی، پرتاب مستقیم چندپین، گتر، فریم دوم با پین‌های مانده، پایان دو بازیکن
- **دانشنامه:** دست ورق‌خوردهٔ دقیق، امتیاز ۱۰ + پاداش برتری، صفر شدن برتری با جواب غلط، چرخش نوبت، بدون تکرار سؤال، انتخاب درستِ بات سخت (≥۸۰٪)
- **ایموجی شاراد:** ۵ معما برای هر نفر بدون تکرار، جابجایی گزینه‌ها هرگز درستی را نمی‌شکند (۲۰۰ حالت)، برندهٔ امتیازی، سلامت بانک
- **زنجیرهٔ کلمات:** کلمهٔ معتبر → حرف بعدی، رد شروع غلط/تکراری/ناموجود، نرمال‌سازی آ→ا، جان و حذف بازیکن، بقای آخرین نفر، «حرف جدید» فقط وقتی حرف تمام شده، بات سخت = کمترین ادامه برای حریف، سلامت واژه‌نامهٔ fa/en (هر حرف پایانی ≥۲ کلمهٔ آغازین)
- **حافظه:** چیدمان متقارن بر اساس تعداد بازیکن، جفت = مالکیت + نوبت اضافه، عدم تطبیق = برگشت + چرخش نوبت، پایان با آخرین جفت، بات سخت جفت دیده‌شده را همیشه پیدا می‌کند، فاز ۲۵ بذر
- **اسکچ:** کپی کامل = ۱۰۰، بوم خالی = ۰، کپی نزدیک > دوردست، بات سخت > بات آسان (همان بذر)، چرخش ۳ دور × نفرات، رد ارسال خارج از نوبت
- **گرگینه:** توزیع نقش (گرگ ۱/۲ بسته به جمعیت + فالگیر + پزشک)، ترتیب شب گرگ→پزشک→فالگیر، نجات پزشک، اعدام با اکثریت ساده و مساوی = حذف‌نشدن، گرگ‌ها هرگز هم‌گروه را نمی‌خورند، پیروزی تیمی (مرده‌ها هم می‌برند)، فاز کامل بات برای میزهای ۵–۸ نفره
- **جاسوس:** چرخش نقش جاسوس بین همه، گزینه‌های خدمه از خود کلمه و گزینه‌های جاسوس هرگز از کلمهٔ واقعی (ناوردی تضمینی)، سرنخ → رأی → حدس، امتیاز ۲/۱/۳، فاز کامل بات ۳–۶ نفره
- **بانکرول:** پرداخت ضریبی بر اساس فاصله (×۵ تا ×۱)، تیرک = ضرر دوبرابر، رد شدن با هزینه، حذف ورشکسته، بازپخش ورق، EV بات‌ها (پاس در فاصله‌های مرده، شرط کسری از بانک)
- **مینی‌گلف:** بازپخش قطعی مسیر توپ (ورودی یکسان = مسیر یکسان)، جریان «همان بازیکن تا پایان حفره»، سقف ۸ ضربه، بامپرهای فیزیکی، مجموع ضربه‌ها برنده
- **دارت:** هندسهٔ واقعی تخته (شعاع‌ها و ترتیب ۲۰ بخش استاندارد)، گاو ۵۰/۲۵، سه‌گانه/دوگانه، بوست = برگشت کل نوبت، پایان دقیق روی صفر، بات سخت T20 با پراکندگی گاوسی
- **نبرد دریایی:** ناوگان ۵-۴-۳-۳-۲، چیدمان تصادفی/اعتبارسنجی، اصابت = حفظ نوبت، لاشهٔ کشتی غرق‌شده برای هر دو طرف عمومی، برنده = غرق کامل ناوگان، بات hunt با پاریتی + حالت هدف
- **ریورسی:** گشایش کلاسیک ۴ دیسک، برعکس‌کردن خطوط با ضد wrap، پاس خودکار، برنده با اکثریت دیسک (مساوی = هر دو)، بات سخت ۲-پلی + وزن‌دهی مکانی + تحرک
- **برو ماهی بگیر:** دست‌ها به‌صورت ضریب رنک (۱۳×۴)، برد همهٔ رنک در hit + نوبت اضافه، ماهیِ شانسی، کتاب چهارتایی، اتمام تضمینی وقتی حوض خالی و دست‌ها خشک می‌شوند، بات از لاگ عمومی دارندهٔ قطعی را استخراج می‌کند
- **مین‌روب:** تختهٔ مشترک ۱۲×۱۲ با ۲۲ مین، امن بودن نخستین کلیک، باز شدن خودکار صفرها، هر خانهٔ سالم +۱ و مین −۵ و پاس نوبت، پایان با باز شدن همهٔ خانه‌های سالم، بات frontier-scoring با تشخیص مین/امن قطعی
- **اسکی‌بال:** انتگراتور ۴۸۰Hz (اصطکاک لاین/سکو، دیوارهٔ elastics، رمپ ۸–۱۲)، افت توپ فقط وقتی آرام روی حفره باشد، ۸ حفرهٔ ۱۰۰/۵۰/۳۰/۲۰، تست دسترس‌پذیری همهٔ حفره‌ها با sweep قدرت، بات سخت تقریباً همیشه حفرهٔ ۱۰۰
