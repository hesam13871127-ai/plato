# 🎲 پلاتو | Plato

باشگاه بازی‌های رومیزی سه‌بعدی — بازسازی از صفر، موج به موج.
A 3D board-game club — rebuilt from scratch, wave by wave.

**Stack:** Vite + React 18 + TypeScript (strict) · React Three Fiber (three.js) · Zustand · Vitest

```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit (strict)
npm test           # engine unit tests (vitest)
npm run build      # typecheck + production build
```

## معماری سه‌لایه (هر بازی)

هر بازی دقیقاً از سه لایهٔ مستقل ساخته می‌شود:

| لایه | مسیر | توضیح |
|---|---|---|
| 🧠 `engine` | `src/games/<id>/engine.ts` | منطق خالص و immutable: `createInitialState / validate / applyAction / legalActions / chooseBotMove` + رابط `GameEngine<S, A>` در `src/core/types.ts`. تصادف فقط از طریق RNG seed شده تزریق می‌شود → کاملاً قابل تست. |
| 🎨 `board` | `src/games/<id>/Board.tsx` | صفحهٔ سه‌بعدی با React Three Fiber: نور/سایه، انیمیشن damp/hop، هایلایت حرکات مجاز، تعامل با کلیک/هاور. |
| 🛍 `shop` | `src/games/<id>/meta.tsx` | اسکین‌های مهره/صفحه/میز + پیش‌نمایش سه‌بعدی + آموزش `fa/en` + لوگوی سه‌بعدی. |

اجزای مشترک:
- `src/core/` — تایپ‌ها، ریجیستری بازی‌ها، `useGameRuntime` (درایور نوبت/ربات/پاداش)
- `src/ui/` — هاب، ستاپ بازیکن (۲–۴ نفره، انسان/ربات با ۳ سطح)، فروشگاه، HUD، ماژول‌های سه‌بعدی مشترک
- `src/state/` — پروفایل (سکه، خرید، اسکین فعال) با persist روی localStorage
- `src/i18n/` — فارسی (RTL) / English

اقتصاد: برد مقابل ربات → سکه (۴۰/۷۰/۱۲۰ بر اساس سختی) → خرید اسکین از فروشگاه.

## پوشش تست (۴۶ تست سبز)

- **دومینو:** پخش ۲۸ تایل، گشاینده با بلندترین دوبله، جهت‌گیری چین، کشیدن/ردشدن، مسدودشدن، امتیاز pips
- **منچ:** خروج با ۶، زدن روی خانهٔ ساده، امن بودن ستاره‌ها، ورود دقیق به خانه، سه‌شش، برد ۴ مهره، بازی کامل ربات‌ها
- **اُچو:** دک ۱۰۸تایی، تطبیق رنگ/عدد/وایلد، skip/reverse (۲ نفره = skip)، draw2/+4، قرعه‌کشی و پاس، امتیازدهی، reshuffle
- **Connect4:** گرانش، ستون پر، برد افقی/عمودی/مورب، مساوی، بوت بلاک/برد فوری، بازی کامل minimax عمق ۶
- **داما:** حرکت جلو، زدن اجباری، زنجیرهٔ ضربه، تاج‌گرفتن و پایان نوبت، پادشاه چهارجهته، باخت با بی‌حرکتی
